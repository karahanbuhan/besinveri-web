# BesinVeri Web
BesinVeri yazılımının web üzerinde çalışmak üzere geliştirilmiş arayüzü. BesinVeri API ile doğrudan iletişime geçip istenen sorguların sonuçlarını şık bir tasarım ile kullanıcılara sunar. [API kaynak koduna ulaşmak için tıklayın](https://github.com/karahanbuhan/besinveri-api).  

## Kurulum & Çalıştırma
Proje şu anda geliştirme aşamasında olduğu için kurulum ve çalıştırma talimatları gelecekte değişiklik gösterebilir. Backend Framework'ü olarak Flask kullanılmaktadır ve öncelikle bir sanal çalıştırma ortamı oluşturulması gerekmektedir.

1. Sanal çalıştırma ortamını (venv) ayarlayın:
`.\.venv\Scripts\activate`
2. Flask ile web sunucusunu başlatın:
`flask run`
